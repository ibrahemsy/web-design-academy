# أكاديمية تصميم الويب | Web Design Academy

منصة تعليمية عربية مبنية باستخدام Flutter Web وSupabase، مع واجهة RTL ودعم الإنجليزية.

## رابط النسخة المنشورة
https://ibrahemsy.github.io/web-design-academy/

## الميزات الحالية

### الحسابات والصلاحيات
- يستطيع المدرّس والمدير التبديل بين وضع الإدارة ووضع التعلّم من داخل الجلسة نفسها، دون تغيير دور الحساب أو صلاحياته الأصلية؛ في وضع التعلّم يمكنهما التسجيل في الدورات المنشورة ومشاهدة الدروس وحفظ التقدم وأداء الاختبارات.
- تسجيل حساب وتسجيل دخول بالبريد وكلمة المرور.
- استعادة كلمة المرور عبر البريد الإلكتروني.
- أدوار منفصلة: طالب، مدرّس، مدير.
- لا يمكن للمستخدم تغيير دوره من الواجهة.
- التحقق من ملف الصلاحيات قبل فتح التطبيق، مع إيقاف آمن عند فشل التحقق.
- تعديل الاسم الظاهر من الملف الشخصي.
- لوحة مدير لإدارة أدوار الحسابات مع منع إزالة دور آخر مدير.
- قائمة طلاب لكل دورة مع متابعة الدروس المكتملة ونسبة التقدم.
- لوحة متابعة للمدرّس والمدير تعرض عدد الطلاب، متوسط إنجاز الدروس، الشهادات الصادرة والمتبقية، وعدد الاختبارات والمحاولات والاجتياز ومتوسط الدرجات لكل دورة.
- المدرّس يرى مؤشرات دوراته فقط، بينما يستطيع المدير مراجعة جميع الدورات.

### الدورات والدروس
- إنشاء الدورات كمسودات، تعديل بياناتها، نشرها وأرشفتها.
- تسجيل الطلاب في الدورات المنشورة.
- إضافة الدروس وتعديلها وإتاحتها كمعاينة مجانية.
- رفع ملفات MP4 وWebM وMOV إلى مساحة تخزين خاصة.
- روابط مشاهدة مؤقتة للفيديوهات.
- حذف ملف الفيديو المرفوع تلقائياً عند فشل إنشاء سجل الدرس.
- حفظ تقدم الطالب واستئناف مشاهدة الدرس من آخر موضع محفوظ.

### الاختبارات
- إنشاء اختبارات متعددة الأسئلة مع درجة نجاح قابلة للتحديد وحد أقصى للمحاولات (أو محاولات غير محدودة).
- تعديل عنوان الاختبار والأسئلة وحذف الأسئلة.
- عرض الاختبارات للطلاب المسجلين في الدورة المنشورة.
- التصحيح داخل قاعدة البيانات، وليس داخل تطبيق العميل.
- لا تُرسل الإجابات الصحيحة للطالب قبل التسليم.
- سجل محاولات ودرجات الطالب.
- لوحة نتائج للمدرّس تشمل المحاولات والمتوسط وعدد الناجحين.

### الشهادات
- إصدار شهادة بعد إكمال جميع دروس الدورة واجتياز جميع اختباراتِها.
- التحقق من الاستحقاق داخل قاعدة البيانات، وليس في تطبيق العميل.
- رمز شهادة فريد، مع حفظ اسم الطالب وعنوان الدورة كما كانا وقت الإصدار.
- صفحة «شهاداتي» وميزة التحقق العام من رمز الشهادة.
- سجل الشهادات في schema خاصة، دون إتاحة الوصول المباشر إلى الجدول عبر Data API.

### الأمان
- Row Level Security على جداول البيانات المكشوفة.
- دوال داخل schema خاصة لقراءة الاختبارات وتصحيحها وعرض النتائج.
- سياسات خاصة لرفع الفيديوهات وقراءتها، بما فيها المعاينات المنشورة.
- مفاتيح العميل العامة فقط؛ لا تستخدم service_role أو Secret key في Flutter.

## التشغيل محلياً

يتطلب Flutter SDK حديثاً:

```bash
flutter pub get
flutter run -d chrome
```

## إعداد متغيرات Supabase

القيم الافتراضية تشير إلى مشروع الأكاديمية الحالي. ويمكن تجاوزها وقت البناء:

```bash
flutter build web --release \
  --base-href /web-design-academy/ \
  --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

لا تضع مفاتيح Supabase السرية أو service_role داخل التطبيق أو GitHub.

## قاعدة البيانات

ملفات التغييرات المتسلسلة موجودة في `supabase/migrations/` من `0001` إلى `0025`. راجع [دليل إعداد Supabase](docs/SUPABASE_SETUP.md) قبل تطبيقها على مشروع جديد.

## النشر

يعمل GitHub Actions عند كل push إلى `main`:
- تثبيت Flutter stable.
- جلب الحزم.
- بناء Flutter Web.
- نشر `build/web` على GitHub Pages.

ملف سير العمل: `.github/workflows/deploy.yml`.

## التحقق قبل الإطلاق

راجع [قائمة فحص الإطلاق العربية](docs/RELEASE_CHECKLIST_AR.md) لإجراء اختبارات القبول والأمان والنشر قبل استقبال الطلاب.

## حدود يجب معرفتها قبل الإطلاق العام

- يلزم اختبار فعلي بحساب طالب ومدرّس ومدير بعد إعداد المستخدمين والأدوار.
- لم يتم تنفيذ اختبار قبول شامل لجميع المسارات على متصفح حقيقي حتى الآن.
- رفع الفيديو يعتمد حالياً على تحميل الملف إلى ذاكرة المتصفح قبل رفعه؛ الملفات الكبيرة جداً قد تحتاج لاحقاً إلى رفع resumable/chunked.
- لا توجد حالياً بوابة دفع أو نظام رسائل أو إدارة حضور.
- الشهادات قابلة للطباعة بتصميم عربي A4 أفقي، ويمكن حفظها بصيغة PDF من نافذة الطباعة في المتصفح.
- التحقق العام من الشهادة متاح من شاشة الدخول دون إنشاء حساب؛ لا تُعرض إلا بيانات الاسم والدورة وتاريخ الإصدار ورمز الشهادة.
- المدرّس والمدير يستطيعان مراجعة حالة إصدار الشهادات للطلاب في كل دورة وتنزيل تقارير CSV للطلاب والتقدم والاختبارات والشهادات.
- لوحة متابعة الدورات تعرض مؤشرات التسجيل والتقدم والاختبارات والشهادات، مع روابط مباشرة إلى قوائم الطلاب وتقارير الشهادات.
- يُنصح بمراجعة حدود التخزين والبريد وخطة Supabase قبل استقبال أعداد كبيرة من المستخدمين.
