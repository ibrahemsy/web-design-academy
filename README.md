# Web Design Academy | أكاديمية تصميم الويب

تطبيق Flutter تعليمي بواجهة عربية RTL ودعم الإنجليزية، لتعليم تصميم وتطوير مواقع الويب.

## الموجود في النسخة الأولية
- لوحة رئيسية وكتالوج دورات.
- صفحات استكشاف الدورات ومتابعة التعلم والملف الشخصي.
- واجهة تجريبية للتبديل بين وضع الطالب والمدرس.
- بطاقات دورات وتقدم تعليمي تجريبي وهيكل دروس.
- تصميم متجاوب للهواتف والشاشات الكبيرة.
- إعداد GitHub Actions لبناء Flutter Web والنشر على GitHub Pages.

## التشغيل
يتطلب Flutter SDK حديثاً:

```bash
flutter pub get
flutter run -d chrome
```

## بناء الويب
```bash
flutter build web --release --base-href /web-design-academy/
```

## النشر
سير العمل في `.github/workflows/deploy.yml` يبني التطبيق وينشر مجلد `build/web` عند كل تحديث إلى `main`.

رابط الموقع المتوقع بعد نجاح النشر:
https://ibrahemsy.github.io/web-design-academy/

قد يلزم فتح Settings → Pages في المستودع واختيار GitHub Actions كمصدر للنشر.

## ملاحظة مهمة
هذه نسخة واجهة MVP. تسجيل الدخول، الحسابات الحقيقية، صلاحيات المدرسين والطلاب، إنشاء الدورات والدروس، رفع الفيديوهات وتخزينها، والاختبارات تحتاج ربط Backend مثل Supabase. وضع المدرس الحالي مجرد تبديل تجريبي للواجهة وليس نظام صلاحيات آمناً.
